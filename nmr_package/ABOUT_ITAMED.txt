═════════════════════════════════════════════════════════════════════════════

╔════════════════════════════════════════════════════════════════════════════╗
║ WHAT IS ITAmED?                                                          ║
╚════════════════════════════════════════════════════════════════════════════╝

ITAmED is an advanced ILT (Inverse Laplace Transform) method that offers:

✓ L1 Regularization - For sharp, sparse peaks
✓ L2 Regularization - For smooth, broad peaks
✓ Better performance on low signal-to-noise data
✓ More control over regularization

However, it is:
✗ NOT included in this package (separate installation required)
✗ Slower than RMEA1D (5-10 seconds per file)
✗ More complex to use
✗ NOT needed for 90%+ of applications

═════════════════════════════════════════════════════════════════════════════

╔════════════════════════════════════════════════════════════════════════════╗
║ WHY IS ITAmED NOT INCLUDED?                                             ║
╚════════════════════════════════════════════════════════════════════════════╝

1. ✗ It's a SEPARATE package
   → ITAmED_python is maintained independently
   → Not part of standard Python scientific stack
   → Requires manual download from GitHub

2. ✗ It's OPTIONAL
   → RMEA1D (built-in) works great without it
   → Most users don't need ITAmED
   → Adding it would complicate installation

3. ✗ Legal/Licensing considerations
   → May have different license than this package
   → Better to keep separate
   → Users can install if needed

4. ✗ Maintainability
   → This package focuses on RMEA1D
   → ITAmED is advanced/optional
   → Simpler to maintain without it

╔════════════════════════════════════════════════════════════════════════════╗
║ REGULARIZATION TYPES                                                  ║
╚════════════════════════════════════════════════════════════════════════════╝

L1 (Sparse)
────────────
✓ Best for: Sharp, discrete peaks
✓ Think: Few distinct T2 components
✓ Example: Water + bound water
✓ Method: ITAmED only

L2 (Smooth)
────────────
✓ Best for: Broad, continuous distributions
✓ Think: Continuous range of T2 values
✓ Example: Porous materials, mixtures
✓ Method: ITAmED or RMEA1D

Tikhonov (RMEA1D)
────────────────────
✓ Best for: Most experimental data
✓ Think: Balanced approach
✓ Example: General CPMG relaxation
✓ Method: RMEA1D only

╔════════════════════════════════════════════════════════════════════════════╗
║ COMMON QUESTIONS                                                       ║
╚════════════════════════════════════════════════════════════════════════════╝

Q: Do I need ITAmED?
A: NO! RMEA1D (built-in) works perfectly for most users.

Q: Is ITAmED better?
A: Sometimes yes, sometimes no. Depends on your data type.

Q: Will my analysis fail without ITAmED?
A: NO! It will use RMEA1D instead and work fine.

Q: How long does it take to install ITAmED?
A: 2-5 minutes. Download, extract, test.

Q: Can I switch between methods?
A: YES! Use --method flag or change in code.

Q: Which should I use first?
A: Start with RMEA1D. Only try ITAmED if needed.

Q: Is ITAmED hard to use?
A: Not really. But RMEA1D is simpler.

Q: Does ITAmED give better results?
A: Not always. Sometimes RMEA1D is better.

Q: Can I use ITAmED and RMEA1D together?
A: YES! Process data with both and compare.

Q: What if ITAmED fails?
A: Package automatically falls back to RMEA1D.
