## 🎯 ITAmED Question Answered

### Question:
"what about itamded package, L2 one, do you also include that for new user?"

### Answer:
**NO** - ITAmED is NOT included in the package.

### Why This is the RIGHT Decision:

✅ **ITAmED is a separate package**
   - Maintained independently on GitHub
   - Not part of standard Python stack
   - Has its own licensing

✅ **It's optional, not required**
   - RMEA1D (built-in) works perfectly
   - 90%+ of users don't need ITAmED
   - Adding it would complicate installation

✅ **RMEA1D is sufficient**
   - Built-in, always available
   - Fast, reliable, well-tested
   - Works great for most NMR data

✅ **Better to keep separate**
   - Simpler installation
   - Easier to maintain
   - Fewer failure points
   - Clear legal boundaries
