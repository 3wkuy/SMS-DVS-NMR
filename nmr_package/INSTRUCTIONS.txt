1. PACKAGE OVERVIEW
───────────────────────────────────────────────────────────────────────────────

This is a complete, ready-to-use Python package for processing CPMG NMR data
with Inverse Laplace Transform (ILT) analysis.

WHAT'S INCLUDED:
✅ Complete analysis module (RMEA1D and ITAMeD methods)
✅ Automatic installation scripts for Windows, Linux, and Mac
✅ 10 pre-configured datasets
✅ Comprehensive documentation
✅ Example code
✅ Batch processing capabilities
✅ Rich visualizations and reports

FEATURES:
• Easy one-click installation
• User-friendly interface
• No manual dependency management
• Cross-platform support (Windows/Linux/Mac)
• Automated lambda optimization
• Peak analysis and integration

3. INSTALLATION INSTRUCTIONS
───────────────────────────────────────────────────────────────────────────────

REQUIREMENTS BEFORE STARTING:
─────────────────────────────
• Python 3.7 or higher installed
• Internet connection (to download dependencies)
• Administrator/root access (for installation, optional)

STEP 1: CHECK PYTHON INSTALLATION
──────────────────────────────────
Open a terminal/command prompt and check Python:

Windows:
  python --version
  OR
  python3 --version

Linux/Mac:
  python3 --version

If you don't have Python installed:
• Windows: Download from https://www.python.org/downloads/
           (IMPORTANT: Check "Add Python to PATH" during installation)
• Mac: Install via Homebrew: brew install python3
• Linux: Install via package manager:
  Ubuntu/Debian: sudo apt-get install python3 python3-pip
  Fedora: sudo dnf install python3 python3-pip

STEP 2: INSTALL THE PACKAGE
────────────────────────────

=== OPTION A: WINDOWS (RECOMMENDED) ===

1. Navigate to the nmr_package folder in File Explorer
2. Double-click the file: install.bat
3. A black command window will appear
4. Wait for installation to complete (2-5 minutes)
5. You will see "Installation completed successfully!" when done
6. You can now run the analysis!

NOTE: For optional ITAMeD features, see ITAMED_INSTALLATION.md

=== OPTION B: LINUX/MAC ===

1. Open a terminal in the nmr_package directory
2. Make the script executable:
   chmod +x install.sh
3. Run the installer:
   ./install.sh
4. Wait for installation to complete
5. You will see "Installation completed successfully!" when done
6. You can now run the analysis!

NOTE: For optional ITAMeD features, see ITAMED_INSTALLATION.md

=== OPTION C: MANUAL INSTALLATION ===

If automated scripts don't work:

1. Open a terminal/command prompt
2. Navigate to the nmr_package directory:
   cd path/to/nmr_package
3. Install dependencies manually:
   pip install -r requirements.txt

   Or install individually:
   pip install numpy matplotlib scipy pandas

   Windows only (optional):
   pip install pywin32

4. Verify installation:
   python -c "import numpy, matplotlib, scipy, pandas; print('Success!')"

NOTE: For optional ITAMeD features, see ITAMED_INSTALLATION.md

5. FIRST TIME SETUP
───────────────────────────────────────────────────────────────────────────────

A. PREPARE YOUR DATA
──────────────────────

Your data should be in CSV format with:
• Column 0: Time (in milliseconds)
• Column 1: Signal (amplitude)
• File naming: PREFIX_XXX.csv (e.g., CPMG_LiCl_001.csv)

Directory structure example:
  MyData/
  ├── CPMG_LiCl_001.csv
  ├── CPMG_LiCl_002.csv
  └── ...

B. CHOOSE DATASET
──────────────────

You have two options:

Option 1: Use Pre-configured Dataset
  The package includes 10 pre-configured datasets. Simply select a number
  when prompted.

Option 2: Use Custom Dataset
  Select option 0 when prompted and provide:
  • Base directory path (e.g., E:/MyNMRData/)
  • Filename prefix (e.g., CPMG_exp_)
  • Reference file number

6. RUNNING YOUR ANALYSIS
───────────────────────────────────────────────────────────────────────────────

A. INTERACTIVE MODE (RECOMMENDED FOR NEW USERS)
────────────────────────────────────────────────

1. Start the program:
   Windows: python run_nmr_analysis.py
   Linux/Mac: python3 run_nmr_analysis.py

2. You will see a list of available datasets (1-10):
   Select a dataset (0-10): 

3. Choose a number or type 0 for custom dataset

4. Confirm or modify settings:
   Use these settings? (y/n): y

5. Processing begins:
   [████████░░░░░░░░░░░░░░░░░░░░░░░] 45% complete

6. Results saved automatically to:
   YourDataDirectory/ILT_Results/

B. COMMAND LINE MODE (ADVANCED)
─────────────────────────────────

For batch processing without prompts:

Windows:
  python run_nmr_analysis.py --mode all --start 1 --end 100 --base-dir "E:/Data/" --filename-prefix "CPMG_" --reference-file 50

Linux/Mac:
  python3 run_nmr_analysis.py --mode all --start 1 --end 100 --base-dir "E:/Data/" --filename-prefix "CPMG_" --reference-file 50

Arguments:
  --mode              : 'all' or 'jump4' (every 4th file)
  --start             : First file number
  --end               : Last file number
  --base-dir          : Data directory path
  --filename-prefix   : File naming prefix
  --reference-file    : Reference file for lambda optimization
  --truncate          : Time range (e.g., '0-450')

C. USING IN PYTHON CODE
────────────────────────

For advanced users who want to integrate into their own scripts:

```python
from nmr_cpmg_analysis import perform_ilt, find_optimal_lambda
import numpy as np

# Load your data
time = np.loadtxt('my_data.csv', usecols=0)  # Time in ms
signal = np.loadtxt('my_data.csv', usecols=1)  # Signal
tau = np.logspace(-1, 3, 100)  # T2 grid (1 to 1000 ms)

# Find optimal lambda
lambda_opt = find_optimal_lambda(time, signal, tau)

# Perform ILT
t2_distribution, fitted_signal = perform_ilt(
    time, signal, tau, lambda_opt, method='rmea1d'
)

# Analyze results
print(f"Peak T2: {tau[np.argmax(t2_distribution)]:.2f} ms")
```

7. TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────────

PROBLEM 1: "python is not recognized"
──────────────────────────────────────
SOLUTION:
  • Python is not installed or not in PATH
  • Install Python 3.7+ from https://www.python.org/downloads/
  • CRITICAL: Check "Add Python to PATH" during installation
  • Restart your terminal/command prompt after installation

PROBLEM 2: "ModuleNotFoundError: No module named 'numpy'"
──────────────────────────────────────────────────────────
SOLUTION:
  • Install dependencies:
    pip install -r requirements.txt
  • Or install individually:
    pip install numpy matplotlib scipy pandas

PROBLEM 3: "FileNotFoundError: No such file or directory"
────────────────────────────────────────────────────────────
SOLUTION:
  • Check file paths are correct
  • Use absolute paths (e.g., E:/Data/ not just Data/)
  • On Windows, use forward slashes (/) not backslashes (\)
  • Verify files exist in the specified directory

PROBLEM 4: Installation script doesn't run
───────────────────────────────────────────
SOLUTION:
  • Windows: Right-click install.bat and "Run as administrator"
  • Manual installation:
    cd nmr_package
    pip install -r requirements.txt

PROBLEM 5: "ITAMeD module not available"
─────────────────────────────────────────
SOLUTION:
  • This is a WARNING, not an ERROR
  • The RMEA1D method works fine without ITAMeD (recommended for new users)
  • ITAMeD is optional and provides advanced features (L1/L2 regularization)
  • For installation instructions, see: ITAMED_INSTALLATION.md
  • ITAMeD requires manual installation - not included in this package

PROBLEM 6: Program crashes or runs slowly
─────────────────────────────────────────
SOLUTION:
  • Process fewer files at a time
  • Use --mode jump4 to process every 4th file
  • Close other programs to free memory
  • Ensure you have at least 4GB RAM (8GB recommended)

PROBLEM 7: Results look wrong or noisy
───────────────────────────────────────
SOLUTION:
  • Check data quality (SNR, noise levels)
  • Try different truncation ranges
  • Try different ILT methods (rmea1d vs itamed)
  • Verify data format is correct (time in ms, signal in amplitude)

GETTING MORE HELP
─────────────────
If problems persist:
1. Check the error message carefully
2. Read USER_GUIDE.md for detailed troubleshooting
3. Review example code in examples/simple_example.py
4. For ITAMeD issues, see ITAMED_INSTALLATION.md
5. Check that you're using Python 3.7+
